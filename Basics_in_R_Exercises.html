Exercise 1 · Recognising valid names

Which names can you use directly as object names in R? Decide without running code first. Then correct the invalid names.

weight1
2c_length
data.new
_new.data.1b
1b.da
ta.experiment
new_data_6
last_trial.c
data.as.formated.by.jack.the.other.day
d1
.new_data
.2data

Hint: Names can start with a letter or a period. A period at the beginning must not be followed by a digit. R distinguishes uppercase and lowercase letters.

Solution to Exercise 1

The valid names are weight1, data.new, ta.experiment, new_data_6, last_trial.c, data.as.formated.by.jack.the.other.day, d1, and .new_data.

The invalid names are 2c_length, _new.data.1b, 1b.da, and .2data. Possible alternatives are c_length2, new.data.1b, b1.da, and data2.

Reserved words such as if and TRUE also cannot be used as ordinary object names. Short, descriptive names make code easier to read.

Exercise 2 · Predicting and running code

  1. Predict the result of the last line. Then run the code.

var_b <- 9
var_a + var_b
  1. Change var_a to 10. Calculate the sum again. Which object was overwritten?
  2. Add a comment to your script. Comment out a calculation and check whether it runs.
Solution to Exercise 2

The first sum is 189. Assignments store values; they normally do not display them directly.

var_a <- 10
var_a + var_b
# This sum is 19.
# 1 + 1

var_a was overwritten. Text following # on the same line is not executed as code.

Exercise 3 · Creating and selecting vectors

  1. Create a factor called colours containing six colour names of your choice.
  2. Use : and square brackets to display the third, fourth, and fifth entries.
  3. Create a numeric vector called numbers containing 3, 6, and 9.
  4. Find its length. Then add 1 to each element.
Solution to Exercise 3

One possible solution:

colours <- as.factor(c("red", "blue", "green", "yellow", "black", "white"))
colours[3:5]
numbers <- c(3, 6, 9)
length(numbers)
numbers + 1

The length is 3. Adding 1 gives 4, 7, and 10. colours[3:5] selects entries. The factor levels also shown in the output describe the possible categories.

Exercise 4 · Using functions

  1. Repeat the entire vector numbers from Exercise 3 five times. Store the result as numbers_repeated.
  2. Calculate its sum and its length.
  3. Explain the difference between a function name and an argument using sum(numbers_repeated) as an example.
Solution to Exercise 4
numbers_repeated <- rep(numbers, 5)
sum(numbers_repeated)
length(numbers_repeated)

The sum is 90 and the length is 15. sum is the function name; numbers_repeated is the argument supplied to it.

Exercise 6 · Selecting rows and summarising values

  1. Create data_nm, containing only rows where typeOfS == "nm".
  2. Use summary() to check your selection.
  3. Calculate the mean of sDur in data_nm.
  4. Use R's help or a search engine to find the function for the standard deviation. Calculate the standard deviation of sDur in data_nm.

Hint: Use subset() as in our example with "pl".

Solution to Exercise 6
data_nm <- subset(data_s, typeOfS == "nm")
summary(data_nm)
mean(data_nm$sDur)
sd(data_nm$sDur)

sd() calculates the sample standard deviation. Use ?sd for help. If another dataset contains missing values, these functions may return NA without further arguments. Adding na.rm = TRUE excludes missing values from the calculation.

Exercise 7 · Installing a package

  1. Install ggplot2.
  2. Load the package using library().
  3. Explain the difference between these two steps.

You do not need to create a plot with ggplot2 for these exercises. Installation requires an internet connection.

Solution to Exercise 7
install.packages("ggplot2")
library(ggplot2)

Installation adds the package to a package library on your computer. library() loads it for the current R session. You normally do not need to reinstall it each time you start R, but you do need to load it again in a new session.

Exercise 8 · Rounding a mean

  1. Calculate the mean of the age column in data_s.
  2. Round the result to two decimal places.
  3. Explain why this initially gives a mean across data rows. What happens if one participant occurs more than once?

Hint: You can store the mean in an object first and pass that object to round().

Solution to Exercise 8
mean_age <- mean(data_s$age)
round(mean_age, 2)

The result for the supplied CSV is 29.11. Participants with more rows contribute more often to this mean. It therefore does not automatically give the mean age of the different participants. Calculating a mean using one row per participant is beyond this exercise.

Exercise 10 · Renaming and counting factor levels

Use data_s_edit from Exercise 9.

  1. Display the current levels of pauseBin.
  2. Replace "pause" with "yes" and "no_pause" with "no".
  3. Use table() to count the observations in each category.
  4. How many data rows contain a pause? Why should you check the mapping between the old and new labels?

Hint: Use the pattern levels(x)[levels(x) == "old_label"] <- "new_label".

Solution to Exercise 10
levels(data_s_edit$pauseBin)
levels(data_s_edit$pauseBin)[levels(data_s_edit$pauseBin) == "pause"] <- "yes"
levels(data_s_edit$pauseBin)[levels(data_s_edit$pauseBin) == "no_pause"] <- "no"
table(data_s_edit$pauseBin)

The supplied CSV contains 59 rows with a pause (yes) and 91 without a pause (no). Replacing labels by position without checking could reverse their meanings. Selecting the original labels makes the mapping explicit.

The original data in data_s remain available.

Solution to Exercise 11
names(data_s_edit)[names(data_s_edit) == "item"] <- "word"
names(data_s_edit)
head(data_s_edit$word)

Later code must use the new column name, word. Renaming the column does not change its values.

Bonus exercise · Saving and reusing data

  1. Save data_nm as only_nm_s_data.csv in your course folder.
  2. Read this file into a new object called data_nm_check and inspect its first few rows.
  3. Also save data_nm as an R data file and load it again.

Hint: write.csv(..., row.names = FALSE) prevents an extra column of row numbers. For save(), specify the filename using file =.

Solution to Bonus exercise
write.csv(data_nm, "only_nm_s_data.csv", row.names = FALSE)
data_nm_check <- read.csv("only_nm_s_data.csv")
head(data_nm_check)
save(data_nm, file = "data_nm.RData")
load("data_nm.RData")

CSV stores a table as text. An R data file preserves the R object, including its data types. load() restores objects under their saved names and can overwrite existing objects with those names.
