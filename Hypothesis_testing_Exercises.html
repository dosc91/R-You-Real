load("fictional_ldt.RData")

This loads a data frame called data_ldt. Use this name throughout the exercises.

No packages are needed. Use 0.05 as the significance level for all tests in this worksheet.

The columns

Column Meaning

There are no missing values. Reaction times are recorded for correct and incorrect responses.

Exercise 3 · First t-test: words and nonwords

Question: Do words and nonwords differ in mean reaction time?

  1. Complete: H₀: The mean reaction time for words is ______ the mean for nonwords. H₁: The two means ______.
  2. Run the code below. It compares both directions: either group could be faster.
  3. Find the two group means and the p-value in the output.
  4. Is the p-value below 0.05? What can you conclude?
t_type <- t.test(rt_ms ~ type, data = correct_ldt)
t_type

In rt_ms ~ type, the left side gives the measurements and the right side gives the groups. data = correct_ldt tells R which dataset to use.

Solution to Exercise 3
t_type <- t.test(rt_ms ~ type, data = correct_ldt)
t_type

H₀: The two population means are equal. H₁: They differ.

R runs a Welch two-sample t-test. It reports t ≈ 5.62, df ≈ 481.60, and p ≈ 3.287e-08. This p-value is below .001, and therefore below .05. The notation e-08 means “multiply by 10⁻⁸”; the value is very small, not zero.

We reject H₀. There is evidence of a difference in mean reaction time. In these fictional data, words received faster correct responses than nonwords.

The output lists nonwords first. Read the group labels to identify each mean.

Exercise 4 · Another t-test: lowercase and uppercase words

Optional extra practice.

Question: Do lowercase and uppercase words differ in mean reaction time?

  1. Use words_rt from Exercise 2. Does it include incorrect responses or nonwords?
  2. Create subsets for lowercase and uppercase words. Calculate their mean reaction times.
  3. State H₀. Adapt the t-test from Exercise 3: change the grouping column to case and the dataset to words_rt. Save the result as t_case and display it.
  4. Is the result significant at .05? Does it establish that the two population means are identical?
Solution to Exercise 4
lowercase_rt <- subset(words_rt, case == "lowercase")
uppercase_rt <- subset(words_rt, case == "uppercase")
mean(lowercase_rt$rt_ms)
mean(uppercase_rt$rt_ms)
t_case <- t.test(rt_ms ~ case, data = words_rt)
t_case

words_rt contains correct word responses only.

H₀: The population mean reaction time is the same for lowercase and uppercase words.

The means are 644.9 ms for lowercase and 662.8 ms for uppercase. R reports t ≈ −1.18, df ≈ 276.76, and p ≈ .238.

The p-value is above .05, so we do not reject H₀. The sample means differ, but the test does not provide sufficient evidence of a population difference. It does not establish that the population means are identical.

Exercise 6 · First chi-square test: accuracy for words and nonwords

Question: Does the proportion of correct responses differ between words and nonwords?

  1. State H₀ in one sentence.
  2. Run the test below using the counts from Exercise 5. Keep correct = FALSE to use the same version as in class.
  3. Find the p-value. Is it below .05?
  4. Use the test result and the percentages from Exercise 5 to describe the finding.
  5. Run chi_type$expected. What counts would we expect if both groups had the same accuracy?
chi_type <- chisq.test(accuracy_type, correct = FALSE)
chi_type
Solution to Exercise 6
chi_type <- chisq.test(accuracy_type, correct = FALSE)
chi_type
chi_type$expected

H₀: The population proportion of correct responses is the same for words and nonwords.

R reports χ² ≈ 14.20, df = 1, and p ≈ .000164. This is below .05, so we reject H₀.

There is evidence that accuracy differs between words and nonwords. In these fictional data, accuracy is higher for words: 93% versus 83%.

Under H₀, the expected counts are 36 incorrect and 264 correct responses in each group. The observed counts differ from those expected counts.

Exercise 8 · What can we conclude?

  1. Which test did we use for reaction times? Which did we use for counts of correct and incorrect responses?
  2. Complete this sentence: “A p-value asks how likely a result at least as extreme as ours would be, assuming ______.”
  3. Correct these statements:
    • “A p-value of .238 means there is a 23.8% probability that H₀ is true.”
    • “A result above .05 proves that the groups are the same.”
    • “A significant result tells us how large the difference is.”
  4. Write one sentence reporting your result from Exercise 3 and one reporting your result from Exercise 6.
Solution to Exercise 8
  1. t-test: Compare mean reaction times. Chi-square test: Compare the counts across categories to assess whether the proportion correct differs.
  2. “…assuming H₀ is true.”
  3. Corrections:
    • A p-value of .238 means that, if H₀ were true, results at least as extreme as ours would occur about 23.8% of the time. It does not give the probability that H₀ is true.
    • A result above .05 means we do not reject H₀ at this level. It does not establish that the groups are the same.
    • A significant result alone does not tell us the size of the difference. Look at the means or percentages as well.
  4. Example reports:
    • “Correct responses were faster for words (653.7 ms) than for nonwords (722.8 ms), Welch’s t(481.60) = 5.62, p < .001.”
    • “Accuracy was higher for words (93%) than for nonwords (83%), χ²(1) = 14.20, p < .001.”

Both reports refer to the fictional practice data.
