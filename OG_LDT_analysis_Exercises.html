R You Real? Lexical Decisions and Data Analysis

These exercises use simulated data calibrated to Meyer and Schvaneveldt (1971). They reproduce the published patterns and rounded statistics. They are not the authors’ original observations.

Work in your own R script. Try each task before opening its sample solution. Use base R throughout. The main route is Exercises 1–7. Exercises 8–9 extend the work to the comparisons between experiments and the authors’ processing-time estimates.

Exercise 3 · The association effect in Experiment I

Connection to the paper: Table 1 and p. 229: associated versus unassociated word pairs; paper F(1, 11) = 20.6, p < .001.

  1. State H₀ for the association comparison.
  2. Run the code below. %in% keeps rows matching either listed condition.
  3. In summary(), read the condition row. Find F, the p-value, and the residual degrees of freedom.
  4. Use the means to identify the direction of the difference.
  5. Does the conclusion agree with the paper?
assoc_I <- subset(exp_I, condition %in% c("associated", "unassociated"))
fit_assoc_I <- aov(mean_rt ~ participant_id + condition, data = assoc_I)
summary(fit_assoc_I)
aggregate(mean_rt ~ condition, data = assoc_I, FUN = mean)

aov() runs the ANOVA. mean_rt is the outcome. participant_id allows for differences in participants’ overall speed. condition is the comparison we want.

Sample solution to Exercise 3
assoc_I <- subset(exp_I, condition %in% c("associated", "unassociated"))
fit_assoc_I <- aov(mean_rt ~ participant_id + condition, data = assoc_I)
summary(fit_assoc_I)
aggregate(mean_rt ~ condition, data = assoc_I, FUN = mean)

H₀: The population mean correct RT is the same for associated and unassociated word pairs.

The condition row gives F(1, 11) = 20.606, p ≈ .000845. The 11 residual degrees of freedom appear on the Residuals row.

Reject H₀ at .05. Associated pairs have faster correct responses: 854.773 versus 940.227 ms, an advantage of 85.454 ms.

This reproduces the paper’s 85 ms advantage, F = 20.6, and p < .001 after rounding. The F value itself does not give the direction.

Exercise 7 · Report the findings in relation to the paper

Connection to the paper: Tables 1–2 and discussion, pp. 229–233: distinguish the measured patterns from the proposed retrieval mechanism.

Write short answers:

  1. Report the Experiment I association RT result with the means, F, degrees of freedom, and p.
  2. How does the association effect compare across the two experiments descriptively?
  3. Give one comparison with a significant RT result but a nonsignificant error result.
  4. What must an explanation account for besides the association advantage?
  5. Does matching the paper with these simulated data independently confirm the authors’ memory model?
Sample solution to Exercise 7
  1. “Associated word pairs received faster correct responses (854.773 ms) than unassociated pairs (940.227 ms), F(1, 11) = 20.61, p < .001.”
  2. Both show an association advantage: about 85.45 ms in I and 116.55 ms in II. This descriptive difference alone does not establish a difference between the population effects. Exercise 8 tests that comparison.
  3. Examples include association in I, mixed-pair order in II, and nonword/nonword versus unassociated words in II.
  4. The explanation must account for the reversal of the mixed-pair order advantage, the nonword-pair patterns, and the error results.
  5. No. We deliberately constructed these data to match the paper. They teach the analyses. The paper’s results themselves do not uniquely identify spreading excitation or location shifting.

Use the outcome, comparison, and direction when interpreting a p-value.

Exercise 9 · Extension The proposed processing times

Connection to the paper: p. 231: the authors interpret selected differences as approximate processing times, conditional on their serial-decision account.

  1. The Experiment I order difference is about 183 ms. The authors use it to estimate a lexical decision time. Calculate its mean and standard error using scores_I$order_effect.
  2. Calculate the difference in word_mean between experiments and its standard error.
  3. Calculate the between-experiment difference for word_nonword_rt and its standard error. Why is this different from the overall mixed_mean difference?
  4. Why should these be described as model-dependent estimates?

Guided calculations:

scores_I <- subset(scores, experiment == "I")
scores_II <- subset(scores, experiment == "II")
mean(scores_I$order_effect)
sd(scores_I$order_effect) / sqrt(nrow(scores_I))

For a difference between the two experiment means, use the supplied standard-error formula in the solution. No additional significance test is needed here.

Sample solution to Exercise 9
scores_I <- subset(scores, experiment == "I")
scores_II <- subset(scores, experiment == "II")

mean(scores_I$order_effect)
sd(scores_I$order_effect) / sqrt(nrow(scores_I))

mean(scores_II$word_mean) - mean(scores_I$word_mean)
sqrt(var(scores_II$word_mean) / nrow(scores_II) +
     var(scores_I$word_mean) / nrow(scores_I))

mean(scores_II$word_nonword_rt) - mean(scores_I$word_nonword_rt)
sqrt(var(scores_II$word_nonword_rt) / nrow(scores_II) +
     var(scores_I$word_nonword_rt) / nrow(scores_I))
Proposed time estimate Simulated difference ms Simulated SE ms Paper
Top-word lexical decision 183.253 13.984 183 ± 14 ms
Comparing matching lexical decisions 216.005 67.633 216 ± 68 ms
Comparing nonmatching decisions, word above nonword 231.429 76.001 231 ± 76 ms

The 231 ms estimate uses only word-above-nonword trials. The 357 ms task difference averages both mixed-pair orders.

The authors interpret the differences using assumptions about processing order and extra operations. The experiment does not directly time those mental stages. Changes in participants, trial proportions, practice, and payment also qualify the cross-task interpretation.
